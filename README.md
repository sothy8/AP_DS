## 📖 Course Overview

The **Advanced Programming for Data Science** course focuses on equipping students with essential software engineering and advanced programming practices tailored for data science workflows. Key areas covered include:

- Writing clean, maintainable, and modular Python code.
- Adhering to professional style guides (**PEP 8**) and software craftsmanship standards.
- Advanced data structures, functional paradigms, and object-oriented programming (OOP).
- Efficient data processing, manipulation, analysis, and visualization.
- Practical debugging strategies and test-driven development.

## 🚀 Getting Started

### Prerequisites

- Python 3.10+ installed
- Git

### Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sothy8/AP_DS.git
   cd AP_DS
   ```

2. **Switch to the TP branch:**
   ```bash
   git checkout TP
   ```

3. **(Optional) Create and activate a virtual environment:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # On macOS/Linux
   # venv\Scripts\activate   # On Windows
   ```
