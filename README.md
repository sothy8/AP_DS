# AP_DS

## Description

This repository contains the practical works (TP) for the Advanced Programming to Data Science course in I5 for the 2026-2027 academic year. 
The course aims to equip students with practical skills in advanced programming techniques relevant to data science applications. It covers various aspects of data manipulation, analysis, visualization, and model building using Python. The TP sessions focus on hands-on implementation of these techniques through a series of exercises and projects. The repository is organized into weekly TP folders, each containing Jupyter notebooks, datasets, and supplementary materials.
