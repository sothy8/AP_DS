## 🎯 Course Overview & Objectives

The **Advanced Programming for Data Science** course is designed to transition students from basic scripting to professional software engineering practices tailored for data science and AI. 

The primary objectives of the course are:
- Mastering advanced Python paradigms (Object-Oriented Programming, functional programming, modular design).
- Writing clean, maintainable, and readable code adhering strictly to **PEP 8** standards.
- Developing robust data pipelines, exploratory workflows, and efficient numerical computing algorithms.
- Applying systematic debugging, testing, profiling, and error-handling techniques.
- Gaining hands-on experience in collaborative version control, clean commits, and branch management.

## 📚 Course Modules & Topics

The course curriculum is divided into core thematic units:

| Module | Topic | Key Focus Areas |
| :--- | :--- | :--- |
| **Module 1** | **Python Engineering & Clean Code** | Code cleanliness, readability, modularity, PEP 8 style guide, functions, classes, modules, packages, and debugging techniques. |
| **Module 2** | **Advanced Python & OOP** | Object-Oriented design (inheritance, polymorphism, encapsulation), magic methods, decorators, generators, and exception handling. |
| **Module 3** | **Numerical Computing & Performance** | Vectorization, NumPy arrays, memory layout, broadcasting, and optimizing computational bottlenecks. |
| **Module 4** | **Data Wrangling & Manipulation** | Advanced Pandas techniques, data cleaning, transformations, indexing, grouping, merging, and missing data imputation. |
| **Module 5** | **Exploratory Data Analysis & Visualization** | Statistical data exploration, interactive charts, and storytelling using Matplotlib, Seaborn, and Plotly. |
| **Module 6** | **Applied ML Pipelines & Software Delivery** | Feature pipelines, Scikit-learn integration, model persistence, testing, and production-ready code organization. |

## 🛠️ Course Activities & Learning Methods

The course emphasizes an active, hands-on pedagogical approach combining theory with continuous practice:

### 1. 📖 Lecture & Concept Sessions (CM)
- Deep-dive into software design patterns, algorithmic complexity, and data science architecture.
- Code walkthroughs, live demonstrations, and analysis of anti-patterns vs. best practices.

### 2. 💻 Practical Works (Travaux Pratiques / TP)
- **Weekly Guided Labs:** Hands-on exercises reinforcing lecture concepts through concrete implementation.
- **Problem Solving:** Designing modular solutions, writing clean functions, and following PEP 8 conventions.
- *All practical submissions, reports, and code are tracked in the [`TP`](https://github.com/sothy8/AP_DS/tree/TP) branch.*

### 3. 🗣️ Student Presentations & Knowledge Sharing
- Interactive class sessions where students present and discuss clean code principles, refactoring techniques, and debugging strategies with peers.

### 4. 🧪 Debugging & Code Audits
- Systematic error identification using stack traces and debuggers.
- Peer code reviews to improve readability, maintainability, and execution efficiency.

### 5. 🚀 Capstone / Applied Projects
- End-to-end data science projects building complete pipelines from raw data ingestion to evaluation and clean reporting.

## 📌 Coding Standards & Guidelines

All assignments and coursework submitted under this repository follow these core principles:
1. **PEP 8 Compliance:** 4 spaces per indent level, line lengths $\le 79$ characters, snake_case naming for variables/functions.
2. **DRY Principle:** "Don't Repeat Yourself" — modularize repetitive logic into reusable functions or classes.
3. **Meaningful Naming:** Variables, functions, and classes must reflect their true intent.
4. **Self-Documenting Code:** Write expressive code supplemented with docstrings for non-trivial logic.
